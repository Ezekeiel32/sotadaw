# Drill (UK/NY) arrangement

Bounce comes from the 808 syncopation, not hat density. Classic bar: 808 at 0, 1.75, 2.5 (pitch move), 3.25;
kick layer only on 0; snare 2.0 + ghost 3.75 (vel 0.35). Dark minor keys; melodic = ominous bell, string stab,
or detuned piano, sparse (2-4 notes/2 bars), heavy reverb (fx_reverb mix 0.35 size 4). Strings sustain
root-b2 movement for menace. Slide feel: adjacent 808 notes 1-3 semitones apart with len overlapping slightly.
